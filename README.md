# Plantilla web ViveroSmart
Plantilla frontend para el proyecto de gestión, trazabilidad y proyección de viveros frutícolas en Duitama, Boyacá.

## Abrir
1. Descomprime el archivo ZIP.
2. Abre `index.html` con Chrome, Edge o Firefox.
3. No requiere instalación para visualizar el prototipo.

## Carpetas
- `index.html`: estructura y contenido.
- `css/styles.css`: estilos y diseño adaptable a móviles.
- `js/app.js`: navegación y acciones demostrativas.
- `assets/`: espacio para imágenes, logos y recursos.

## Módulos
Panel principal, viveros, lotes y trazabilidad, producción, inventario, clientes y proveedores, ventas y costos, reportes.

## Alcance
Es una plantilla de interfaz (frontend), no un sistema terminado. Incluye datos ficticios y botones de demostración. No incluye inicio de sesión, base de datos, API, generación real de QR ni guardado de formularios. Para ello se debe implementar un backend y conectar una base de datos.
